Action	Command	Description
List Interfaces	tshark -D	Shows all available network interfaces with their index numbers.
Live Capture	tshark -i <interface>	Captures and streams live traffic to stdout from a specified interface (e.g., -i 1 or -i eth0).
Limit Packets	tshark -i <interface> -c 100	Automatically stops the capture after receiving a specific number of packets.
Write to File	tshark -i <interface> -w output.pcapng	Saves raw packet data directly to a file for later analysis instead of printing to screen.
Read from File	tshark -r input.pcapng	Reads and analyzes an existing packet capture file.
Display Filter	tshark -r input.pcapng -Y "http"	Filters the output using standard Wireshark display filter syntax.
